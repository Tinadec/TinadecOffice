# CLA Signatures

This directory stores the contributor signatures collected by the CLA Assistant
workflow (`.github/workflows/cla.yml`).

- `version1/cla.json` — current signature store, created automatically on the
  first signed contribution for **CLA.md / CLA.zh-CN.md (version 1)**.

Do **not** hand-edit `cla.json`; the workflow manages it. Keep this directory
tracked in Git so the signature store is durable and auditable.
