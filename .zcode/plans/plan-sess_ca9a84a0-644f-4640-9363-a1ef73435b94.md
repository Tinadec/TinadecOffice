## 目标
把模型中心的"供应商"选项卡与"API/本地连接"选项卡合并：合并后只保留一个"供应商"选项卡，显示**已添加的供应商实例**列表；模板完全由前端 `PROVIDER_TEMPLATES` 提供（不再依赖 Core 的 suppliers 目录），新增供应商走已有的前端模板选择器。

## 现状（已验证）
- 模型中心当前 5 个 tab：`suppliers` / `api` / `models` / `cli` / `acp`（SettingsPage.vue:613-619）。
- `suppliers` tab 是 Core `model-center/overview.suppliers` 的只读卡片目录（2121-2165），每个卡片"添加"按钮走 `openAddModal`；Core 目前只硬编码返回 1 个 `openai` 模板（ControlPlaneEndpoints.cs:16），且前端 `PROVIDER_TEMPLATES`（providerTemplates.ts，470 行）已具备完整模板能力 —— 这正是"供应商选项卡重复无用"的根因。
- `api` tab 显示已添加实例表格（2317-2422），`modelCenterRows` 已 `.filter(row => row.kind === 'instance')`（691-696），即**只显示实例**，正是合并后想要的样子。
- 前端已有完整模板选择器：command bar `+ 新增供应商`（1861）→ `handleAddProviderClick`（928）→ `showTemplatePicker`（3979）→ 按分类分组的 `pickerTemplates`。新增入口已就绪。
- Core suppliers 数据虽然只渲染在 suppliers tab，但还被 `supplierTemplates`（620）、`pickerTemplates`（625）、`currentTemplate`（623）、`openAddModal` 默认（894）、`modelCenterRows` 第三参数（693）、`providerPresentation`（1701）依赖。合并后这些都改为纯前端 `PROVIDER_TEMPLATES`。

## 改动清单（全部在 apps/desktop，不改 Core/Gateway 后端）

### 1. 删除"供应商"目录 tab，默认 tab 改为 api
- `modelCenterSections`（613-619）：删除 `suppliers` 条目；把 `api` 条目的 `label` 从 `centerApiConnections` 改为 `centerSuppliers`（"供应商"）。合并后 4 个 tab：供应商 / 模型 / CLI / ACP。
- `modelCenterSection` 默认值（429）：`'suppliers'` → `'api'`。
- `focusModelProviderList`（919-926）：`filter === 'available' ? 'suppliers' : 'api'` → 恒为 `'api'`（`'available'` 分支是死代码，唯一调用者 1972 传的是 `'issues'`）；`modelProviderListRef` 在 suppliers section 的重复绑定随 section 删除自然消失。

### 2. 删除 suppliers 卡片目录模板块（2121-2165）
移除整个 suppliers `<section>`（含空状态 `noSuppliers`、`coreCatalog` badge、`supplierSummary`/`supplierTransportLabel`/`supplierCredentialLabel`/`catalogReadinessByDriver` 在卡片上的调用）。

### 3. 模板逻辑改纯前端 PROVIDER_TEMPLATES
- `supplierTemplates`（620-622）：删除（其引用全部改本地模板）。
- `currentTemplate`（623）：`supplierTemplates.get(driver) ?? findTemplate(driver)` → `findTemplate(driver)`。
- `pickerTemplates`（625-636）：改为 `computed(() => PROVIDER_TEMPLATES)`，删除 Core suppliers 合并与 `supplierPresentationAliases` 去重逻辑。
- `openAddModal` 默认模板（894-898）：`modelCenterOverview?.suppliers[0] ? providerTemplateFromSupplier(...) : PROVIDER_TEMPLATES[0]` → 恒 `PROVIDER_TEMPLATES[0]`。
- `modelCenterRows` 第三参数（693）：`[...supplierTemplates.value.values()]` → `PROVIDER_TEMPLATES`。
- `providerPresentation`（1701）：`supplierTemplates.get(driver) ?? findTemplate(driver)` → `findTemplate(driver)`。

### 4. 清理死代码 / import
- 删除函数：`supplierSummary`（1691）、`supplierTransportLabel`（1671）、`supplierCredentialLabel`（1681）、`catalogReadinessByDriver`（674-680）。**保留** `warningCatalogTemplates`（671，模型诊断区 2020 仍使用）和 `providerPresentation`（api 表格品牌图标仍用）。
- 删除 import：`providerTemplateFromSupplier`（91）、`supplierPresentationAliases`（94，改纯前端后不再需要）。
- 保留 `ModelCenterFilter` 类型及其 `'available'` 字面量不动（类型仍合法，`'available'` 只是未使用；`modelProviderFilter` 445 仍在用）。

### 5. 空状态引导（小改进）
api 表格空状态（2419-2422，`noProviderResults`）加一个"新增供应商"按钮 → `handleAddProviderClick`，让"还没有供应商时点这里新增"更直接。需要时在 zh-CN/en 补一个按钮文案 key（可复用 `addProvider`，不必新增）。
