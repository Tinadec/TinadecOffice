## 目标
为模型中心的 **CLI 选项卡**加入两个能力：
1. **CLI 自发现**：扫描本机常见 CLI 安装位置，列出已内置支持的 CLI（claude-cli / codex-cli / cursor-acp / opencode 等），已检测到的可"快速连接"，未检测到的灰显提示。
2. **CLI 删除**：CLI 运行时行上增加"删除"按钮（目前只有"编辑"，无法删除）。

## 现状（已验证）
- CLI 运行时是 `connection_kind: 'cli'` 的 `model-provider` 记录，与 API 连接存在**同一张** `model_provider_instances` 表；CLI 字段（binary_path/home_path/server_url/launch_args）存在版本化 JSON 配置 blob 里。
- **删除已天然支持**：`DELETE /api/v1/model-providers/{id}`（Core:ControlPlaneEndpoints.cs:14 → ControlPlaneService.DeleteProvider:88；Gateway:index.ts:543；Desktop:api.ts:1082 `deleteModelProvider`）。CLI 行目前没有删除按钮，复用现有 `deleteProvider(runtime.provider_instance_id)`（SettingsPage.vue:941，含确认框 + 删除 + 双中心刷新）即可。
- CLI 选项卡模板在 SettingsPage.vue:2132-2168：每行只有"编辑"按钮（2153-2161），标题区（2133-2138）无任何按钮槽。
- 前端已有 CLI 模板：providerTemplates.ts 的 `codex-cli`(384) / `claude-cli`(399) / `cursor-acp`(414) / `opencode`(429)，均有 binary_path/home_path/server_url/launch_args placeholders。

## 架构决策
- **自发现在后端（Core）做**：符合"Core 拥有 readiness/discovery 语义"的原则，且浏览器渲染进程无法可靠扫描文件系统/PATH。新增一个 Core 端点，镜像现有 `RefreshProviderModels` 与 `ProbeDefaultExecutable` 模式。
- **触发方式**：CLI 选项卡标题区放一个"自发现"按钮，手动点击才扫描（不拖慢进入页面）。
- **展示范围**：列出全部内置支持的 CLI；检测到的显示实际路径 + "快速连接"按钮，未检测到的灰显"未检测到"。
- **删除**：复用 `deleteProvider`，在 CLI 行加 `Trash2` 按钮。

## 改动清单

### Core（TinadecCore）
**`TinadecCore/Runtime/ControlPlaneService.cs`** — 新增 `DiscoverCliRuntimes(CancellationToken)`：
- 内置已知 CLI 表：`claude-cli`(可执行名 `claude`，home `~/.claude`)、`codex-cli`(`codex`，home `~/.codex`)、`cursor-acp`(`cursor-agent`)、`opencode`(`opencode`，server_url `http://127.0.0.1:4096`)。
- 探测逻辑：对每个已知 CLI，在 PATH 各目录 + 常见安装目录（`%USERPROFILE%\.local\bin`、`%APPDATA%\npm`、`%LOCALAPPDATA%\Programs\...` 等）查找可执行名（Windows 上试 `.exe`/`.cmd`/`.bat`）；用 `File.Exists`/`GetFullPath`。
- 结合现有 provider 表（`db.Providers`，`DeletedAt == null`）标记已配置的 driver 为 `configured`。
- 返回 `{ cli_runtimes: [...] }`，每条含 `driver`、`display_name`、`binary_path`、`home_path`、`server_url`、`launch_args`、`status`（`found`/`missing`/`configured`）。
- 为可测试性，探测辅助逻辑抽成一个小方法/静态 helper，允许注入 `IEnumerable<string>? searchPaths`（默认取真实 PATH），测试时注入临时目录。
