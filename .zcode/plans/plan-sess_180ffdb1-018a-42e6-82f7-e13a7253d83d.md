## 目标

把功能面板标签栏的 `+` 按钮从"点击返回首页"改为"点击弹出下拉菜单，列出所有可打开的页面，用户选择后打开对应标签页"（类似浏览器新建标签页菜单）。

## 现状与关键约束

- `BrowserTabBar.vue` 的 `+` 按钮当前 `@click="emit('home')"`；8 个页面的元数据目前内联在 `HomePickerCard.vue` 的 `features` computed 里。
- `ui/dropdown-menu.vue` / `ui/popover.vue` 是 `relative`+`absolute` 的非 Teleport 实现，会被 `.wb-stack` 的 `overflow:hidden` 和 `.browser-tab-bar` 的 `overflow-x:auto` 裁剪，因此下拉菜单必须 **Teleport 到 body + fixed 定位**。
- 打开页面的能力已存在：UIE `openCard` 命令（reducer 已有单例自动激活逻辑：git/approval/orchestration/events/doctor/agent 已开则激活；browser/terminal 允许多实例）。下拉只需派发 `openCard`。

## 改动清单

### 新增：`apps/TinadecUI/src/components/cards/home/featureCatalog.ts`
- 导出 `FEATURE_CATALOG: { descriptorId, titleKey, descKey, icon, color }[]` —— 8 个页面的单一数据源（agent/terminal/git/approval/orchestration/browser/events/doctor），从 `HomePickerCard` 内联列表原样提取。

### 修改：`apps/TinadecUI/src/components/BrowserTabBar.vue`
- `+` 按钮改为 `@click="toggleMenu"`，不再 emit `home`；加 `aria-haspopup="menu"` / `aria-expanded`。
- 新增 Teleport 下拉菜单（`<Teleport to="body">`，`position: fixed`，打开时根据触发按钮 `getBoundingClientRect()` 计算 `top/right`，右对齐面板右缘）：
  - 每项：彩色图标块（`--card-color` tile，同 Home 网格视觉）+ 标题 + 单行描述 + approval 待办徽标（复用 `homeController` 计数，与 Home 网格一致）。
  - 样式用共享 surface tokens（`--surface-raised` 底、`--border-card` 边、`--shadow-panel`、hover `--surface-hover`）。
  - 交互：点选 → emit `open-panel` 并关闭；点击外部 / Esc / 窗口 resize → 关闭；`onUnmounted` 清理监听。
- 新增 emit：`open-panel: [descriptorId: string]`。

### 修改：`apps/TinadecUI/src/components/UieStack.vue`
- 处理 `@open-panel="openFeature"` → dispatch `openCard`（scope/expectedRevision 沿用现有模式），单例卡片自动激活、browser/terminal 开新实例。

### 修改：`apps/TinadecUI/src/components/cards/home/HomePickerCard.vue`
- `features` 改为基于 `FEATURE_CATALOG` 派生（approval 在其上附加 badge 函数），行为不变，消除重复元数据。

### 测试与验证
- 新增 `apps/TinadecUI/src/components/cards/home/featureCatalog.test.ts`（8 项、descriptorId 断言）。
- `npm --prefix apps/TinadecUI test` + `npm --prefix apps/desktop test` + `vue-tsc --noEmit` + `npm run build`。
- 浏览器实测：点击 `+` 弹菜单、点选打开对应标签页、已开单例卡片激活而非重复、点击外部/Esc 关闭、菜单不被面板裁剪。

## 不做的事
- 不改 Home 标签本身（仍用于返回首页）。
- 不引入新依赖；不改造 `ui/dropdown-menu.vue`（其非 Teleport 结构无法用于裁剪容器内）。
