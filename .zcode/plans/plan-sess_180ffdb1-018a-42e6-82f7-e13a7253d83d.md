## 目标

让功能面板**折叠态侧栏**（44px rail）除展开按钮、Home 图标外，还**垂直列出所有已打开功能标签的图标**：仅图标、无文字，可点击 → 激活对应标签并展开面板；点击 Home 图标 → 展开并回首页；点击展开按钮 → 仅展开、保持当前标签。

## 关键说明：修改位置

用户要求改 `apps/desktop/src/components/ContextPanel.vue` + `usePanelTabs`，但该组件是旧版遗留（仅 debug 画廊预览，生产不渲染），`usePanelTabs` 也不再驱动实时面板。**当前实际渲染的折叠侧栏是 `apps/TinadecUI/src/components/UieColumn.vue`**（DOM 中 `.float-panel-collapsed-bar.wb-column-rail`），已打开的标签即 UIE 快照 `column.primary.tabIds`。因此本需求在 `UieColumn.vue` 内实现，与 UIE 快照集成（`usePanelTabs` 的数据源等价物）。

## 改动：`apps/TinadecUI/src/components/UieColumn.vue`

### Script
- 引入 `FEATURE_CATALOG`（复用共享目录，图标与标签栏/加号菜单同源）、`type LucideIcon`、`type PersistedCardInstance`。
- 新增 `openFeatureInstances` computed：`column.primary.tabIds` 映射到卡片、过滤掉 `homePicker`（即已打开的功能标签）。
- 新增 `isFeatureActive(instanceId)`：`activeTabId === instanceId`（折叠态高亮当前标签）。
- 新增 `FEATURE_ICON_BY_DESCRIPTOR` Map（由 `FEATURE_CATALOG` 派生）+ `featureIconFor()`（缺省 HomeIcon）。
- 把 `expand(goHome: boolean)` 泛化为 `expand(instanceId?: string | null)`：无参 = 仅展开；带 instanceId = 展开 + `activateCard`。Home 按钮改传 `featureHomeId`。

### Template（折叠 rail 内）
- 展开按钮保留：`@click="expand()"`。
- Home 按钮保留：`@click="expand(featureHomeId)"`（激活首页）。
- 新增功能标签图标按钮（Home 之下垂直排列）：`v-for="inst in openFeatureInstances"`，复用 `.float-panel-collapsed-icon` 类（32×32、单色 muted、hover/active 强调色），`<component :is="featureIconFor(inst.descriptorId)" :size="16" />`，`:title="inst.title"`（悬停提示，标签文本不显示在 rail 上），`:class="{ active: isFeatureActive(inst.id) }"`，`@click="expand(inst.id)"`。

### Style
- `.wb-column-rail` 增加 `overflow-y: auto`（标签多时可滚动）；图标间距沿用全局 `.float-panel-collapsed-bar` 的 `gap: 4px`。
- 折叠/展开动画不动（`.wb-column` 的 `transition: width 0.25s` 已存在，保持现状）。

## 验证
- `vue-tsc --noEmit`、`npm --prefix apps/TinadecUI test`、`npm --prefix apps/desktop test`、`npm run build`。
- 浏览器实测：打开若干标签（git/审批/编排等）→ 折叠 → rail 显示对应图标（无文字）；点击某功能图标 → 面板展开且该标签激活；点击 Home 图标 → 展开回首页；点击展开按钮 → 仅展开保持当前标签。

- 不改变展开态标签栏行为。
