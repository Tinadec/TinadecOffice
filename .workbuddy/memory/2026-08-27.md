## 修复功能面板打开崩溃（Cannot read properties of undefined (reading 'startsWith')）
- 根因：SSE 事件契约错位。前端 `EventEnvelope` 接口（apps/desktop/src/api.ts:461）声明 `type/seq/ts/v` 是**从未存在过的 wire 形状**；Core `TinadecCore/Contracts/Events/EventEnvelope.cs` 实际以 SnakeCaseLower 直出 `event_type/timestamp/version/event_id/run_id`，seq 只藏在 `payload.sequence`（SSE `id:` 行同源）。Gateway proxySse 原样透传。首个 SSE 事件到达时 `event.type.startsWith(...)` 在 undefined 上抛 TypeError，经 rendererErrorFallback 变全屏崩溃覆盖层。崩溃点在 HomeController.ts:426、useAgentActivity.ts:646、DetachedPanelPage.vue:102（均消费 connectEvents 回调）。
- 修复（前端归一化，零后端改动，符合"Core 拥有契约、desktop DTO mirror 对齐"惯例）：`api.ts` 新增导出纯函数 `normalizeEventEnvelope(raw, lastEventId?)`——type←event_type、ts←timestamp、v←version、seq←(payload.sequence → lastEventId → 0，Number.isFinite 链防御)、request_id/trace_id/capabilities 兜底 ''/[]、payload 排除非对象；`connectEvents` 全部 14 个回调入口统一走 `handle`（JSON.parse + try/catch，畸形帧不崩 renderer）。新增 `src/api.test.ts`（happy-dom 环境，7 用例：Core 形状/legacy 形状/seq 兜底/字符串 seq/畸形 payload/空对象 + FakeEventSource 转发测试）。
- 验证：`npx vitest run src/api.test.ts` 7/7 通过；全套 vitest 294 passed/14 skipped/0 fail（14 个 NotificationIslandHost 为预存 skip）；typecheck 仅 4 个存量 Monaco 错误，api.ts 无新增。
- 附带发现（未修）：前端只注册 13 种具名事件 listener，`run.failed`/`model_selection` 等被 EventSource 静默丢弃，`source.onmessage` 是死代码（只收无 event: 帧）；seq 跨 run 从 1 重启，HomeController bySeq Map 会互相覆盖。
