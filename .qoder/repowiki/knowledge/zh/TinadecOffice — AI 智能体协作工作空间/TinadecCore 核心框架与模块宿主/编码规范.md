- 每个业务模块实现 `IModuleRegistrar` 接口并通过 `Register(ITinadecCoreBuilder)` 向构建器声明自身 `ModuleId`，禁止反射扫描，注册顺序由 `TinadecCoreServiceCollectionExtensions` 显式控制。
- 所有数据库访问通过 EF Core DbContext 表达，DbContext 统一使用 `UseTinadecDatabase(serviceProvider)` 扩展根据 `IDatabaseConnectionInfo` 选择 SQLite 或 PostgreSQL。
- DI 服务注册一律采用 `services.TryAddSingleton/Scoped/Transient(...)` 形式，允许宿主覆盖默认实现。
- HTTP 响应 DTO 统一使用 snake_case 命名策略（`JsonNamingPolicy.SnakeCaseLower`）且忽略 null 字段。
- F# 策略文件（ContextBudget、PromptSelection、MemoryScoring、LoopDetection、StateTransition）保持纯函数风格，仅依赖 Abstractions 中的端口接口，不引用任何基础设施。
- 测试项目按职责拆分：`Architecture.Tests` 用 NetArchTest 断言依赖方向，`AgentFramework.Tests` 做冒烟与 F# 互操作验证，`Api.Tests` 用 `WebApplicationFactory` 进行端到端测试。
