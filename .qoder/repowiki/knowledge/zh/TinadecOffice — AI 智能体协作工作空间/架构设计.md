根目录通过 package.json 的 workspaces 与 TinadecOffice.slnx 将四个子模块串联：Desktop（Electron+Vue3，端口 5173）仅调用 Gateway；Gateway（Bun+Elysia，端口 48730）作为唯一对外 BFF，代理 Core 并透传 SSE/WebSocket；Core（.NET 10 + ASP.NET Core + MAF，端口 48731）是唯一状态权威，内部按 foundation/modules/host 分层组织 Contracts/Abstractions/Persistence/VectorStore/Strategies 等子项目；Tool 层（TinadecTools + TinadecTools.Generators）通过 JSON stdin/stdout 被 Core 调用。所有写操作经 Gateway 审批门，API 契约统一 snake_case，数据库抽象默认 SQLite、可选 PostgreSQL。npm run dev 通过 concurrently 同时启动 core/gateway/desktop 三个进程，构建与测试均沿同一脚本链向下分发到各子模块。
