- 每个测试类使用 `[Fact]` 特性标记测试方法，遵循 xUnit 命名约定（如 `PersistsProjectsSessionsMessagesApprovalsAndEvents`）。
- 测试中使用的临时文件或仓库通过实现 `IDisposable` 的辅助类（`TempGitRepo`、`WorkspaceTestDirectory`）管理生命周期，确保测试后清理。
- 测试数据目录统一创建于 `FileToolRuntime.WorkspaceRoot/.tinadec-tools-tests` 下，并以 Guid 或 idPrefix 区分实例。
- Contract 序列化测试使用统一的 `JsonSerializerOptions` 配置 `SnakeCaseLower` 命名策略，断言 JSON 字段名符合契约约定。
- Git 操作通过封装的 `RunGit` / `CaptureGit` 方法执行，失败时抛出 `InvalidOperationException` 并附带错误输出。
