- 所有对外 HTTP 路由统一通过 Elysia 实例链式 `.get/.post/.put/.delete` 注册，并使用 `setStatus(set, result.status)` 同步响应状态码。
- 对 Core 和 Tool Runtime 的 HTTP 调用一律通过 `proxyJson`/`proxySse`/`proxyStream` 等封装函数发起，禁止直接调用 `fetch`，以保证错误码统一（502 + code/message 结构）。
- 请求体参数中的查询字符串通过 `URLSearchParams` 构造，键名按后端约定进行驼峰转换（如 `session_id` → `sessionId`、`run_id` → `runId`）。
- 需要认证的公共路径通过 `isPublicPath` 白名单判断（`/api/v1/health`、`/docs*`），其余路径在云端模式下强制走 `authenticate` 中间件。
- 高风险/中风险工具 ID 集中定义在 `approval.ts` 的 `HIGH_RISK_TOOL_IDS` / `MEDIUM_RISK_TOOL_IDS` Set 中，由 `assessRisk` 统一判定风险等级。
- Code Tool 规格通过 `TOOL_SPECS` 常量对象声明（id/summary/category/requiresApproval/approvalSummary/language_support），并通过 `listCodeToolSpecs` 转换为 DTO 暴露给前端。
