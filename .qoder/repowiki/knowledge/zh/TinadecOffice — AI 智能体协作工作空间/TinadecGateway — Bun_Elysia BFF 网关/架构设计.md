模块以 `src/index.ts` 为唯一入口，使用 Elysia 构建单进程 HTTP 服务器，通过链式 `.onRequest` 中间件实现 CORS → 认证（本地模式跳过，云端模式支持 API Key / JWT HS256）→ 路由注册。

- 依赖方向：index.ts 仅依赖各功能模块的导出函数，不反向被引用；核心客户端 `coreClient.ts` 与 `toolRuntimeClient.ts` 提供统一的 JSON/SSE/Stream 代理能力，被 index.ts、`streaming.ts`、`websocket.ts`、`modelAgentCenter.ts`、`codeTools.ts`、`mcp/mcpRoutes.ts` 复用。
- 配置层：`config.ts` 通过环境变量加载 `GatewayConfig`，并以单例 `getConfig()` 暴露，所有下游模块通过该单例获取 Core/Tool Runtime URL、认证配置等。
- 业务子模块：
  - `auth.ts`：JWT HS256 验证（WebCrypto）、API Key 校验、租户/用户头注入。
  - `approval.ts`：人类操作高风险命令二次确认（449 状态码），维护 HIGH_RISK/MEDIUM_RISK 工具白名单。
  - `codeTools.ts`：内置 Code Tool 规格表（TOOL_SPECS）、Core 审批快照验证、通过 Tool Runtime 执行。
  - `modelAgentCenter.ts`：聚合 Core 的 model-provider-templates/providers/routes/agents 等数据，生成 Model/Agent Center 概览。
  - `websocket.ts`：WS_ROUTES 映射表，将 `/ws/terminal`、`/ws/debug`、`/ws/collaboration` 透传到 Core 或 Tool Runtime。
  - `streaming.ts`：无缓冲流式代理，用于大文件与日志流。
  - `mcp/mcpRoutes.ts`：独立 Elysia 插件，纯代理 MCP server 连接/断开/状态/调用到 Tool Runtime。
- 部署模式：`mode=local`（默认，127.0.0.1:48730，无认证）与 `mode=cloud`（0.0.0.0，可选认证、信任反向代理头）。
