用户拍板三项：形态=混合（模态 + 聚光 + 通知）、必经=只有模型验证、下一步=先落文档。文档已写，实现未开始。

### 探查到的关键事实（都可复验）

- 仓库**完全没有** first-run 机制：`grep -i "oobe|onboarding|firstRun|hasSeen|setupComplete"` 在 `apps/` 零命中；`desktop.toml` 字段只有 gateway_url / user_root / close_to_tray / debug_studio_enabled / companion.enabled。
- 准入判据用 Core 的 10 项 readiness（`ReadinessService.cs:52-56`：database / core_storage / agent_pack / default_mode / model_provider / model_secret / model_route / model_probe / tool_provider / manifest_hash），**不要自己重新判一遍"能不能对话"**。其中 `default_mode` 已经覆盖了"缺默认模式会 409"这条坑。
- **`POST /api/v1/model-probe?force=true` 已存在**：走已解析 chat 路由真发 1 token，10s 超时，60s 缓存，force 绕缓存。桌面端 `api.ts` 还没封装（只有 mockData 和 schema.d.ts 有）。OOBE 的"验证连通"直接复用它，不要自己发探测请求。
- `DevSeed.cs:17-60` 幂等种一个 openai provider 但**故意不写 Key** → 干净环境"有路由没密钥"。引导首屏不能把它渲染成"已配好 OpenAI"，判据用 `secret_reference` 为空。
- `petWindow.cjs:60-83` 是 `alwaysOnTop: true`。若 habits 步一开宠物就建窗，下一步的 Spotlight 会被压住 → 只写 registry enabled，引导结束再 flush（走 `main.cjs:533-537` 的 `tinadec:pet-enabled`）。
- 宠物进首次流程**不需要联网**：`ensureBuiltinPets()` 已把 deepseek / geptia 复制到本地且 `enabled:false`。写成"下载宠物"会凭空多一个失败点。
- UIE 布局可拖拽且持久化（`uie-layout.json`），`presets.ts` 只在无存档时构造 → 聚光灯**不能按坐标**，必须按 descriptor id 找 DOM，找不到降级成普通卡。唯一需要改 TinadecUI 的地方是加 `data-uie-card-id`。
- `ModeSelector.vue` / `PermissionSelector.vue` 是**孤儿组件**（除自身与 parity 测试外无人 import），真实入口在 `ComposerBar.vue:888-897` 的命令面板。桌面端不保存"当前模式"，跟着会话走。
- `App.entry.test.ts:10-13` 固化了"App 在路由页 setup 之前关掉 host gate"的时序；`AppSplash` 的 `entryReady` 由 home 页自己 emit，OOBE 只能挂在其后。

### 设计要点

- 状态不能只存一个 boolean：`firstRun{completedAt, skippedAt, resumeStep}` + `tours[id]{status: done|dismissed|snoozed, until}`，落 `~/.tinadec/state/desktop/oobe.json`（不进 desktop.toml 因为手写 TOML 字段扁平；不进 localStorage 因为清缓存会丢且伙伴窗口读不到）。
- 跳过 ≠ 放弃：`skippedAt` 后不再自动弹，但首页保留常驻细条"还没有可用的模型 · 继续配置"，与 Doctor 卡片 blocked 项共用同一个 resume。
- 新功能引导**状态驱动而非版本驱动**（如宠物引导 = 有宠物但全部未启用），版本号只用于"最多一次"和赛季分组。按 v0.5 写死会漏掉跳版本用户。
- 三原语共享同一套步骤数据：Setup（表单）/ Spotlight（指向真实元素）/ Announcement（复用 NotificationIslandHost）。
- 模块 `apps/desktop/src/oobe/`，`engine.ts` 必须纯函数可单测；不碰 Core/Gateway，不进 UIE 卡片系统（会让 `repair.ts` 得理解"引导"）。
- i18n 独立 `oobe.*` 命名空间，五个语言齐全（`i18nParity.test.ts` 强制）。
- 分期：一期 welcome/provider/verify + 状态机 + 两个 IPC。
