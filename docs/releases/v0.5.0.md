## What's new

- **实时概要（Live Digest）与多维轨迹透明**：右侧一等 Dock 面板与对话顶心跳条通过单向只读旁路 `LiveExplainerService`（`IsObserverRun = true`）持续提炼当前阶段意图、涉及文件变更与上下文占用水位（标记 Compaction 压缩点）及治理哨兵预警；在编排页可下钻实时/回放执行时间轴、轨迹树、`ContextTreemap` 上下文树图与 Winnowing 重叠诊断，看清多智能体与长思维链的每一步推演。
- **Agent Teams v2/v3 异步协作与直通纠偏**：拆掉批量并行屏障，队友升级为独立异步 Actor 调度循环（审批仅挂起当前队友，不阻塞其余并行成员）；新增 `team_tasks` 去中心化原子抢单任务板（支持 `list` / `claim` / `complete` / `release` 与下游依赖自动解锁）及 `team_message` 实时送达；支持从概要条、时间轴或空间画布点击任意活跃队友直接私信纠偏（`steer`）或单独暂停/恢复（`pause` / `resume`）。
- **Figma UI3 风格协作空间画布与白板**：接入 Core SQLite CRDT/LWW 状态引擎与 WebSocket 在线协作中心，支持语义宏观缩放 LOD、常驻可折叠输入框、便利贴/文字/媒体/Section/自由连线与 Smart Guides 智能标尺，并将 Live Digest 摘要与 AI 队友光标心声微气泡实时投影到画布之上。
- **伴侣中枢与 2D 磁吸悬浮胶囊**：打通 `work_session`、浏览器连接器中枢、统一记忆流与 SSE 反向回流；桌面悬浮胶囊重做为带 2D 磁吸贴边、探头/拉手样式的毛玻璃壳体，支持 BYO Live2D 形象导入、自主行动/招募双门审批以及可选系统语音朗读。
- **黑白极简「暖墨」默认外观、macOS 原生标题栏与三步 OOBE**：默认视觉主题切换为 `monochrome` 与暖墨预设（强化主按钮与弹窗对比度并引入微动效），macOS 启用原生红绿灯标题栏融合布局；全新沉浸式三步首次引导（`welcome` / `provider` / `workspace`）自动探测本机 CLI/ACP 运行时并按就绪门控静默配置 `GraphSeedPack v3.7.0`。
- **.NET 11、Bun 与 Vite 8 底层全面升级**：核心与工具运行时迁移至 `.NET 11`（`net11.0`），全工作区 JS/TS 依赖安装、脚本调度与前端打包统一切换至 `Bun 1.3` 与 `Vite 8`（Rolldown），并重塑轻量化 GitHub Actions CI/CD 流水线。

## What's changed

### 新能力

- **异步多智能体执行层与模式拓扑**：Explore-First Team v2 引入 5 类 `team_*` 端口、Worktree 集成、生命周期钩子与按队友隔离的外部 CLI/ACP 会话；V3 解除已有工具回合与可派单队友的串行降级限制；Agent Center 与模式图编辑器全面重构，对接 `IAgentTopologyService` 契约并支持模式级 `instructions`、`bindings`、`relationship` 与草稿隔离。
- **可配置只读实况解说模型与回放**：多模型设置新增 `live_explainer` 专属解说模型槽位与三档开关（`off` 关闭仅 L0 结构化 / `auto` 默认自动 / `always` 全程实时解说），解说章节持久化写入 Run 记录以供事后回放，模型不可用或关闭时自动无缝降级为纯 L0 结构化时间线。
- **浏览器工具 v2 与供应链安全扫描**：新增 `IBrowserConnector`、`EgoLiteBrowserConnector`、OOPIF 跨源框架快照、站点学习存储及内置可调视口预览面板；新增 Microsoft APM 包解析、`${VAR}` 密钥引用校验与 Unicode 隐写走私扫描；内置 Git 工具补充 `stash` 与 `amend` 操作，并提供统一可新建目录的文件选择器。
- **五语种完整本地化与扩展提示词包**：补齐简体中文、繁体中文、English、日本語、Русский 在工作区选择器、伴侣浮窗、空间画布与 Live Digest 面板的翻译键，`GraphSeedPack` 升级至 `3.7.0`。

### 修复

- 修复冷启动残留 SQLite `__EFMigrationsLock` 锁表及 OOBE 阶段 `GraphSeedPack` 检查时序问题，避免异常退出后无法正常初始化。
- 修复存储作用域路径对宿主机顶层符号链接（如 macOS `/var -> /private/var`）的误判拦截，加强沙盒内 `.git/hooks` 与 `.git/config` 只读保护，并为 SQLite 短暂写锁冲突补充事务级安全重试。
- 修复 Gateway SSE 长连接在 30 秒空闲阈值下的意外断流问题，兼容 OpenRouter 与新版 vLLM 的 `reasoning` / `reasoning_details` 思维链响应格式。
- 修复 Tailwind CSS v4 `@source` 工具类扫描遗漏、头像与图标尺寸对齐、VueFlow 基础样式引入以及主按钮对比度边界问题。

### 性能

- 全仓构建链升级至 `.NET 11`、`Bun 1.3` 与 `Vite 8`（Rolldown）原生 bundler，优化多包安装解析、前端产物体积与脚本启动开销。
- 会话事件流改用按 Run 游标断点续传替代全量重放，并加入 JWKS 密钥集缓存与只读状态投影的锁冲突退避重试。
- 完成 GitHub Actions CI/CD 重构，合并冗余构建环节、优化 `Bubblewrap` / `ripgrep` 缓存并清理高耦合脆弱测试。

### 升级须知

- **默认主题一次性迁移**：升级至 `v0.5.0` 后，此前仍使用旧版默认配色（`blue` / `purple`）的客户端将自动一次性切换为新的黑白极简（`monochrome`）主题；你此前手动选择的其他主题色与自定义配置会完整保留，也可随时在设置中切回。
- **macOS 安装包签名状态**：当前 `macOS arm64` 发布包仍未包含 Apple Developer 官方签名与公证；首次启动若被系统 Gatekeeper 拦截，需右键点击应用选择「打开」或在系统隐私与安全性设置中手动允许运行。
- **源码构建环境要求**：若从源码开发或打包，需将本地后端 SDK 升级至 `.NET 11`（`11.0.100`），并使用 `Bun 1.3+` 执行根目录依赖安装与工作区脚本。
